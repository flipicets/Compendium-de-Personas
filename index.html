    Sobre o projeto

    Este site é o projeto final para o RA 3. Ele busca os dados de um arquivo público do repositório Persona Compendium usando fetch, guarda os favoritos no localStorage e envia o formulário de contato com POST.

    As páginas que fizemos foram as de: Explorar (cartões com busca, filtros e favoritos), Ferramentas (calculadora e estatísticas) e Contato (formulário).
